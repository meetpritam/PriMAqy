## 🌟 Key Features & Ecosystem

- **⚡ Modern Architecture**: Built on Next.js 16 (App Router) & React 19 for maximum performance and speed.
- **🛠️ Product Suite**: Features **Toolsetic** and modular developer/creator productivity suites.
- **👨‍💻 Founders Hub**: In-depth founder profiles (`/founders`), interactive study roadmaps, project showcases, and philosophy.
- **📚 Insights & Knowledge Base**: Comprehensive editorial platform with tag filtering, category archives, author pages, and RSS feed (`/rss.xml`).
- **🚀 Startup Anchor & Toolkit**: Essential startup documentation, frameworks, and resource hubs.
- **📱 Responsive & Clean UI**: Engineered with Tailwind CSS v4, Lucide React icons, and permanent Light Mode design system.
- **🔍 Programmatic SEO**: Fully prerendered static & dynamic routes, dynamic XML sitemaps, structured JSON-LD schemas, and OpenGraph tags.
- **💬 Direct Founder Connect**: Integrated instant WhatsApp communication flow (`+91 8252468903`).

## 🚀 Getting Started

### Prerequisites

Ensure you have **Node.js 18.x** or higher installed on your machine.

### Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/kpritamkumar99-create/PriMAqy.git
   cd PriMAqy
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Run Development Server**
   ```bash
   npm run dev
   ```

4. Open `http://localhost:3000` in your browser to see the application live.
